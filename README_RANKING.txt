MINEVORA 11.0 — RANKING GRACZY

1. Otwórz MINEVORA 11.0 i wybierz zakładkę Ranking.
2. Dodaj graczy ręcznie albo użyj „Mój postęp” (odczytuje lokalny XP/PvP).
3. Zdobądź zgodę osób na publiczne wyświetlanie nicków oraz statystyk.
4. Wybierz „Eksport na stronę” i zapisz ranking.json.
5. Wgraj ranking.json do tego samego folderu co ranking.html na GitHub Pages.
6. Każda aktualizacja wyników wymaga ponownego eksportu i wgrania pliku.

Ranking jest lokalny, niezweryfikowany i NIE pobiera wyników z innych serwerów.
Wyniki PvP są wpisywane ręcznie; nie są dowodem umiejętności ani zachowania.
Nie eksportuje kont Microsoft, IP, tokenów, banów ani raportów Fair Play.
Prawdziwy ranking online będzie wymagać serwera API i weryfikacji wyników.
