⬇ Instalacja MINEVORA 11.0

Najprostszy sposób uruchomienia launchera na komputerze z Windows 11. To projekt oparty na Pythonie, a nie klasyczny instalator .exe.

  1. Pobierz plikiKliknij przycisk poniżej i pobierz archiwum najnowszej przygotowanej wersji.

    ⬇ MINEVORA 12.2 — paczka ZIP

  2. Rozpakuj cały folderW Eksploratorze plików kliknij ZIP prawym przyciskiem i wybierz Wyodrębnij wszystkie. Nie uruchamiaj plików bezpośrednio z archiwum.
  3. Sprawdź instalację PythonaJeśli go nie masz, pobierz z python.org. Zalecany Python 3.12 lub 3.13. Podczas instalacji zaznacz dodanie Pythona do PATH.
  4. Zainstaluj wymagane bibliotekiW rozpakowanym folderze uruchom INSTALUJ_ZALEZNOSCI.bat. Wymaga dostępu do internetu przy pierwszej instalacji.
  5. Włącz launcherUruchom URUCHOM_MINEVORA.bat w tym samym folderze. Otworzy się okno MINEVORA.
✓ Pobieranie z tej stronyLink do ZIP działa, gdy plik MINEVORA_11_0_RANKING_GRACZY.zip znajduje się obok poradnik.html na serwerze. Oba pliki są dołączone do paczki strony.

Alternatywa: instalacja przez PowerShell

Otwórz terminal w folderze, do którego rozpakowałeś launcher, i wpisz:

python -m pip install -r requirements.txt
python .\minevora_qt.py

▶ Pierwsze uruchomienie

  1. Otwórz MINEVORAPo uruchomieniu pliku BAT zobaczysz główne menu launchera.
  2. Wybierz wersję Minecraft JavaOtwórz sekcję Instancje i wybierz instalację pasującą do serwera lub modów.
  3. Połącz konto MicrosoftJeżeli chcesz grać na własnym oficjalnym koncie Minecraft Java, skorzystaj z sekcji Microsoft / Zaloguj.
  4. Uruchom gręWybierz profil lub wersję i kliknij przycisk uruchamiania Minecraft w launcherze.
Funkcje wymagające internetu i oficjalnych usług mogą działać dopiero po prawidłowym skonfigurowaniu konta i połączenia. Logowanie Microsoft w tej wersji wymaga dodatkowej konfiguracji.

◉ Logowanie Microsoft

W MINEVORA 10.9 logowanie używa przeglądarki i mechanizmu OAuth. Nigdy nie wpisuj hasła Microsoft w oknie launchera.

  1. Kliknij „Microsoft / Zaloguj”Otwórz ekran logowania w menu launchera.
  2. Jeśli poprosi o Client IDPotrzebujesz identyfikatora z rejestracji aplikacji w Microsoft Entra. Nie jest to Twój adres e-mail ani hasło.
  3. Skonfiguruj aplikację OAuthJeśli masz dostęp, przejdź do Microsoft Entra i sprawdź rejestrację aplikacji oraz zgodną konfigurację przekierowania http://localhost:8765/callback. Konta bez uprawnień do rejestracji aplikacji mogą wymagać innej, zgodnej konfiguracji.
  4. Zaloguj się na stronie MicrosoftPo uruchomieniu procesu otworzy się oficjalna strona Microsoft w przeglądarce; wróć do launchera po autoryzacji.
Uwaga technicznaLogowanie Microsoft nadal wymaga testu w Windows. Jeśli pojawi się błąd, skopiuj komunikat z PowerShell. Nie przesyłaj nikomu tokenów ani kodów autoryzacyjnych.

⚔ PvP Arena i serwery

W panelu PvP możesz wybrać trening Sword, Crystal, Axe, UHC, BedWars lub SkyWars. MINEVORA pomaga zarządzać serwerami, ale same walki rozgrywają się w Minecraft.

  1. Wybierz „PvP Arena”Otwórz odpowiednią pozycję menu po lewej.
  2. Dodaj serwerWpisz jego nazwę i adres. Używaj tylko rzeczywistych adresów, które znasz.

  4. Uruchom MinecraftSkopiuj adres serwera, a następnie w grze otwórz Multiplayer → Direct Connection.
Statystyki walk w PvP Arena są obecnie wpisywane ręcznie. Oficjalne serwery MINEVORA Network i globalny matchmaking pozostają projektem na przyszłość.

🛠 Najczęstsze problemy i rozwiązania

Python: can't open file 'minevora_qt.py'

To zwykle oznacza, że PowerShell jest w złym folderze. Najłatwiej uruchomić URUCHOM_MINEVORA.bat z rozpakowanej paczki. Jeśli używasz terminala, otwórz folder launchera i dopiero wykonaj polecenie:

python .\minevora_qt.py

Możesz też znaleźć plik, używając poniższego polecenia w PowerShell:

Get-ChildItem "$HOME\Downloads" -Filter "minevora_qt.py" -Recurse -File
ModuleNotFoundError: No module named 'PySide6'

Biblioteki nie zostały zainstalowane w używanym interpreterze Pythona. W folderze launchera uruchom:

python -m pip install -r requirements.txt

Jeśli instalacja nie jest możliwa w używanej wersji Pythona, spróbuj zalecanego Pythona 3.12 lub 3.13.

Microsoft prosi o Client ID

To identyfikator aplikacji OAuth (GUID), nie adres e-mail. Wymagana jest konfiguracja aplikacji Microsoft Entra z poprawnym adresem przekierowania. Nie wklejaj hasła ani kodów logowania.

'tuple' object has no attribute 'get'

Ten komunikat może wynikać z niezgodności wersji biblioteki minecraft-launcher-lib z obsługą OAuth. Sprawdź, czy korzystasz z najnowszej paczki, i zaktualizuj bibliotekę:

python -m pip install --upgrade minecraft-launcher-lib

Jeśli błąd nadal występuje, skopiuj pełny Traceback z PowerShell, usuwając z niego wszelkie tokeny autoryzacyjne.

Marketplace nie pokazuje projektu u innych

W obecnej wersji pliki Marketplace są zapisywane na komputerze twórcy. Do wspólnej biblioteki potrzebny jest backend internetowy i system kont.

Nie działa Discord Rich Presence

Sprawdź, czy Discord jest uruchomiony, czy wpisano właściwy Application ID i czy biblioteka pypresence jest zainstalowana.

💾 Backup & Restore — nowy komputer

Wersja MINEVORA 10.1 zawiera osobne narzędzie tworzenia kopii zapasowych. Zapisz swoje światy Minecraft, modele, projekty i lokalne dane launchera przed zmianą komputera.

  1. Na starym komputerzeZamknij Minecraft i launcher. Otwórz folder MINEVORA 10.9, a następnie uruchom URUCHOM_BACKUP_RESTORE.bat.
  2. Utwórz archiwum ZIPZaznacz dane, które chcesz zachować. Dodaj własne foldery projektów, jeśli masz modele Blender lub Blockbench w innych lokalizacjach. Wybierz pendrive lub dysk zewnętrzny jako miejsce zapisu.
  3. Sprawdź kopięUpewnij się, że utworzony plik ZIP ma oczekiwany rozmiar i został zapisany na zewnętrznym nośniku. Nie usuwaj jeszcze starych danych.
  4. Na nowym komputerzeSkopiuj ZIP i folder MINEVORA 10.9. Uruchom URUCHOM_BACKUP_RESTORE.bat, wybierz „Przywróć kopię” i wskaż archiwum.
  5. Zaloguj się ponownieSkonfiguruj uruchamianie Minecraft i konto Microsoft od nowa, a następnie sprawdź światy, profile i Marketplace.
Bezpieczeństwo danychNarzędzie pomija wrażliwe pliki sesji. Archiwum kopii zapasowej nie jest szyfrowane, dlatego nie przesyłaj go publicznie ani nie umieszczaj w otwartym repozytorium GitHub.

? Pytania i odpowiedzi

Czy MINEVORA uruchamia Minecraft Java?

Takie jest zadanie launchera. Do gry na własnym oficjalnym koncie potrzebujesz prawidłowo działającego logowania Microsoft i uprawnień do Minecraft Java Edition.

Czy MineCoins to prawdziwe pieniądze?

Nie. MVC jest obecnie walutą demonstracyjną w lokalnym prototypie.

Czy mogę publikować modele dla wszystkich?

Na razie nie bezpośrednio przez Marketplace MINEVORA. Funkcja zapisu projektów jest lokalna.

Czy antycheat automatycznie banuje?

Nie. Prototyp MINEVORA Guard zapisuje sygnały do sprawdzenia przez administrację. Wymaga testów na serwerze Paper.

Czy poradnik działa bez internetu?

Tak, plik HTML działa lokalnie w przeglądarce. Internet jest potrzebny do otwierania zewnętrznych linków, pobierania bibliotek i logowania.
